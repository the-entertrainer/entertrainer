# Asset licences and provenance

Every third-party file that ships in this site, with where it came from and
under what terms. The rule this table exists to enforce: **a "free download"
label is not a licence.** If an asset's terms cannot be established, it is
replaced with something original rather than shipped on a guess.

Last reviewed: **15 August 2026**.

## Typefaces

Four families, all open-source under the **SIL Open Font License 1.1**, which
permits commercial use, embedding and redistribution. Full licence text for
each is bundled in `docs/licenses/`, as the OFL requires. Files were fetched
from `fonts.gstatic.com` on 15 August 2026, subset to the `latin` and
`latin-ext` ranges as Google serves them, and are otherwise **unmodified**.

These were chosen as the closest open equivalents to a reference publication's
type, which is entirely commercial and licensed per domain — Atlas Grotesk and
Atlas Typewriter (Commercial Type), Tiempos Text (Klim), Gooper SemiCondensed.
None of those can be used here, so each was replaced by role rather than
imitated by name. That substitution is documented at the top of
`assets/css/fonts.css`.

|---|---|---|---|---|---|
| Fraunces | Display — masthead, headlines, card titles | Gooper SemiCondensed | `public/fonts/webfonts/fraunces-var-*.woff2` | 2018 The Fraunces Project Authors | `docs/licenses/OFL-fraunces.txt` |
| Archivo | Interface — navigation, buttons, labels, tool UI | Atlas Grotesk | `public/fonts/webfonts/archivo-var-*.woff2` | 2020 The Archivo Project Authors | `docs/licenses/OFL-archivo.txt` |
| Source Serif 4 | Reading — decks, body copy, captions | Tiempos Text | `public/fonts/webfonts/source-serif-4-var-*.woff2` | 2014 The Source Serif 4 Project Authors (Adobe) | `docs/licenses/OFL-sourceserif4.txt` |
| IBM Plex Mono | Metadata — categories, counts, stamps, indices | Atlas Typewriter | `public/fonts/webfonts/ibm-plex-mono-*.woff2` | © 2017 IBM Corp., reserved font name "Plex" | `docs/licenses/OFL-ibmplexmono.txt` |

**Attribution required?** No — the OFL does not require visible attribution.
The names appear in the site footer and on `/colophon` anyway, because a
publication that argues for showing its workings should show them.

**Reserved font names.** IBM Plex reserves the name "Plex". These files are
unmodified, so nothing here triggers the renaming clause — but any future
subsetting, hinting or instancing of Plex must be published under a different
name.

One remote font remains: the Strong module (`/my-work/strong`) loads **Inter**
from Google Fonts for its own art direction. Inter is also SIL OFL 1.1
(© 2016 The Inter Project Authors). It is the only third-party request the
site makes for type.

## Course media (AI course)

The AI course links out to 31 YouTube videos and 27 web resources. **Nothing is
redistributed** — no video is downloaded, mirrored or re-hosted, and the player
is a facade that contacts YouTube only when a learner presses play, via
`youtube-nocookie.com`. So the question here is verification rather than
licensing, and the register is `content/course/ai/media.ts`.

**Verified on 15 August 2026:** every video id was resolved against YouTube's
own search and oEmbed endpoints. The title, channel and runtime recorded for
each are the values YouTube returned, not values written from memory. Every
resource URL was requested and returned HTTP 200.

## Adding an asset

Record, in this file, before it ships:

1. Local path
2. What it is
3. Creator
4. Source URL
5. The exact licence name and version
6. Whether attribution is required
7. Date checked
8. Any modification made

If any row cannot be filled in with certainty, do not ship the asset — draw
or generate a replacement. An asset that merely *resembles* a public-domain
reference is not itself public domain: the licence belongs to the file, not
to the visual idea.
