# Compact AI Course Screen Map

## Player rule

The AI course retains its seven named lessons, but each lesson is now a collection of short fullscreen learning screens. Every screen has a single job: introduce one idea, examine one visual, make one decision, or complete one practice action. The player shows lesson number and screen number in its compact top course bar. A completed screen may be revisited; the next screen remains unavailable until the current direct action is complete.

## Screen sequence

| Lesson | Screen sequence | Retained visual or activity |
|---|---|---|
| Welcome | Title and purpose; learning objectives | Immersive course cover and clear objectives. |
| 1. Before ChatGPT | Core historical idea; real Turing and ENIAC evidence; early-computing visual; history timeline practice | Real historical media plus the new early-computing bench. |
| 2. What AI is | Task–information–output–check; system signal-board visual; travel estimate activity; human-check decision | New signal-board visual and existing travel example. |

| 5. Modern AI types | Multimodal field-kit visual; real CNN and Astrobee evidence; input-detective game; types map | New field-kit visual plus real-source evidence. |
| 6. Models in the world | Capability boundary; evaluation worktable; infrastructure evidence; evidence-check activity | New evaluation visual plus real server-room evidence. |
| 7. Know AI | Responsible-use checkpoint; safeguards practice; action plan; final knowledge and word match | New responsible-use visual plus existing assessments. |

## Interaction and persistence contract

Screen-level state is saved separately from content state. Existing game state—prediction steps, matching, sort cards, plans, input detective, and safeguards—is preserved. Every activity remains on a dedicated short screen. Top-bar next and back controls move between completed screens only; in-screen Continue controls explain what is released next. There is no public footer and no long document-style module view.
