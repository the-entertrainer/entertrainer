# Compact Course Visual-Storytelling Storyboard

## Shared visual system

The course will use **warm-paper editorial imagery**, **cobalt route marks**, **blue-violet supporting cues**, and **ink-precise linework**. Real photographs establish the people and conditions of work. Original text-free illustrations explain invisible planning relationships. Deterministic interface diagrams explain ADDIE and alignment exactly. Every visual is paired with a caption that states what the learner should notice.

| Visual family | Teaching job | Motion | Accessibility rule |
|---|---|---|---|
| Real work photograph | Ground a concept in people, tools, and context | Slow 10px settle on screen entry; no loop | Descriptive alt text; caption explains relevance |
| Editorial concept illustration | Make an invisible design idea tangible | Route trace draws once; object cards enter in order | Decorative objects omitted from alt text; core concept stated nearby |
| Deterministic diagram | Explain a precise relationship or process | Active node or card changes only after learner action | Full relationship expressed in visible text and DOM order |
| Activity context visual | Give a decision consequence and place | Small state change after choice; no score confetti | Selection, feedback, and completion are never colour-only |

## Asset set to create or source

The implementation requires seven new original text-free educational visuals: learning route, performance-gap field, ADDIE workbench, ADDIE output card family, café task trail, storyboard worktable, and evidence-loop/route-complete still life. The output-card family will be generated as a consistent set of five visuals in one prompt group. The course also requires three additional real contextual photographs: busy closing task, adult workplace learning/observation, and busy service context.

Existing real and credited assets will remain for the opening, analysis, Bloom’s taxonomy, artefact view, and contextual learner moments when they fit the newly defined visual jobs. No visual is added solely to fill a gap: every screen must retain its single-purpose length, clear CTA, and short learner reading load.
