# Introduction to Instructional Design — Course Plan

## Audience and promise

This 15–20 minute module is for a person who has never heard the term **instructional design**. It uses one familiar workplace situation throughout: new café staff must learn to close the counter safely and consistently. The learner will see why a “make a course” request is not the first question an instructional designer asks.

> **Course promise:** By the end, a beginner can explain the job of instructional design and make three sound first decisions about a simple learning problem.

## Learning objectives

**By the End of this module, you will be able to:**

1. **Explain** instructional design in simple words and identify its purpose.
2. **Recognise** the difference between a training need and a non-training problem.
3. **Use** a simple five-step design cycle to plan a small learning experience.
4. **Write** one clear learning objective that connects to an activity and a check for understanding.

## Interaction contract

Every interaction follows an explanation or worked example. No action is presented as a surprise quiz. Feedback explains the reason for the answer and names the design principle the learner should carry forward. All activities work by keyboard and announce their feedback through a live region.

| Interaction | Correct reasoning | Feedback purpose |
| --- | --- | --- |
| First decision: café problem | Gather evidence about the closing task and why the error occurs before deciding on a course. | Establish that analysis comes before format selection. |
| Training-or-environment sort | A missing checklist, unavailable equipment, or unclear process needs more than a course; a skill or knowledge gap may call for learning support. | Make the “not every gap is training” distinction concrete. |
| Objective builder | The strong objective describes an observable learner action in a stated situation. | Move from “understand” to demonstrable performance. |
| Final matching and scenario | Connect each ADDIE action to the practical role it plays. | Retrieval and synthesis, not scoring theatre. |

## Visual and accessibility rules

The visual language will follow Rise’s calm, white reading canvas, generous vertical rhythm, rounded media cards only where appropriate, simple black typography, and one clean blue accent. The visual system is functional: real photographs establish context; deterministic diagrams explain structure; original generated illustrations make invisible design work visible. All media receives informative alt text; diagrams have adjacent text equivalents; activity states use words alongside colour; focus order follows visual order; and `prefers-reduced-motion` removes nonessential reveals.

## Source strategy

The course source panel will cite ATD for the definition and practical role, MIT for learner analysis and objectives, UW Bothell for an adaptable ADDIE explanation, EdTech Books for task analysis, CDC for evaluation, and Articulate documentation for the knowledge-check behaviour. The module will present ADDIE as a useful planning map, not a rigid formula, and will not overclaim that a course alone guarantees performance change.
