# Introduction to Instructional Design — Research Basis

## Course scope

This module is for an absolute beginner. It does not train someone to become an instructional designer in one sitting. It gives the learner a usable first explanation of the field: **start with a real performance need, understand the learner and context, make a clear plan for learning, create and test the support, then improve it using evidence**.

## Rise-style learning design decisions

The rebuilt module will use a calm single-column reading canvas, concise headings, full-width visual breaks, short paragraphs, and one learner decision after each explanation. It will use practice-only knowledge checks, not a decorative quiz after every paragraph. Articulate describes knowledge-check blocks as ungraded ways to reinforce understanding or apply it immediately, with multiple-choice, multiple-response, fill-in-the-blank, and matching formats available [1].

The interaction plan therefore uses one simple scenario choice after the performance-gap explanation, an ADDIE process reveal, an objective-builder practice, a card-sort that distinguishes training and non-training solutions, and a short final knowledge check. Feedback will explain why an option fits or does not fit the design decision.
