# Strict Interface-Copy Audit

## Scope

This audit reviewed new Three Es pages, the compact home, shared footer, and newsletter widget against the anti-generic content skill. The reader needs to identify a destination, understand what it contains, or subscribe without being asked to interpret an interface metaphor or a writerly aside.

| Location | Candidate | Decision | Reason |
|---|---|---|---|
| Home | `Entertrainer / route index` | Remove | It describes the layout, not a visitor need. |
| Home | `Pick a direction.` | Replace | It is a vague interface prompt; `Stories, tools, and courses.` names the content. |
| Home | Five `E01`–`A05` codes | Remove | The codes have no sequence or operational meaning. |
| Home | Five route notes | Remove | Each is a styled aside rather than a factual route description. |
| Home | `Start anywhere. The map is not offended.` | Remove | It is self-aware commentary with no task value. |
| Elevate | `Mind · meaning · useful curiosity` | Remove | The label is abstract and repeats the article destination. |
| Elevate | `What this is for` manifesto | Remove | It announces editorial posture instead of helping a reader choose an article. |
| Elevate | Decorative external-link arrow | Remove | The link text already names the action. |
| Empower | Repeated-work analogy | Replace | A direct tool description is clearer. |
| Educate | `The Three Es` eyebrow | Remove | It repeats the visible route hierarchy. |
| Educate | Slide-and-arrows joke | Replace | The course subjects are more useful. |
| Games | `Games are loading` and legality joke | Replace | A direct coming-soon statement is enough. |
| About Me | `A project I still care about` | Remove | The project title and factual summary already establish relevance. |
| About Me | `refused to remain a work report` | Replace | A factual production-role statement is clearer. |
| Newsletter | `useful oddity`, `content treadmill`, and `manufactured urgency` | Replace | Subscription expectations should be direct. |
| Shared controls | Decorative arrows beside action labels | Remove | The written action communicates the destination. |

## Retained

The article title, factual project details, course names, tool names, image alternatives, privacy wording, navigation labels, and email-handoff explanation remain because they help a visitor act, verify a claim, or understand what the site contains.

## Reusable Rule Added

The anti-generic content skill now rejects route narration, ornamental breadcrumbs, decorative codes, faux editorial labels, self-aware jokes, and commentary on the page’s own layout unless the copy changes what a visitor can do or is required for accessibility or law.
