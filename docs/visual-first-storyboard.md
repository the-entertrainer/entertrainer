# Visual-First Storyboard — From No AI to Know AI

## Editorial change

The course will no longer place every explanatory paragraph in the default reading path. Each lesson will keep one concise lead, one compact paragraph per core idea, one visual explanation, one worked-example statement, and the existing purposeful activity. The remaining evidence-oriented detail will remain available in a clearly labelled **Supporting detail** disclosure for learners who need it.

This does not turn the course into a decorative gallery. Every visual either shows a process, contrast, system boundary, or relationship that the previous text asked learners to hold in memory.

## Visual system

The illustrations will remain wide, text-free, and restrained. They use a blue, off-white, charcoal, and warm-paper palette with tactile editorial collage forms rather than generic robot or circuit imagery. The structured diagrams are HTML and CSS blocks so their labels remain accurate, selectable, responsive, and available to assistive technology.

## Reading rules

Default screens will show four prose units at most before the visual, worked example, or interaction. Supporting detail is available after the core explanation but does not interrupt the main narrative. Sources, feedback, and safety caveats remain visible; only redundant exposition moves out of the primary scan path.
