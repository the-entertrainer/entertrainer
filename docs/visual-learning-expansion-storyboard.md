# Visual Learning Expansion Storyboard

## Scope and acceptance threshold

This expansion adds **at least eighteen new course-specific visual moments** across the two courses: a minimum of eight real-world or primary-source visuals, six original editorial explanations, and four deterministic diagrams or activity boards. It does not count the existing covers, existing Bloom’s figure, existing timeline image, or existing course illustrations. Every visual must answer one learning question, carry useful alt text, and be paired with an explanation, activity, or caption. A generic decorative image is not acceptable.

The existing sequential unlock system remains the pacing mechanism. Within a lesson, a learner encounters an orientation hook, a short explanation, visual evidence, an active decision, feedback, and a recap/transfer prompt. The visual density rises only where it reduces abstraction or supports the learner’s action.

## Shared visual and motion contract

| Pattern | Learning purpose | Full-motion behavior | Reduced-motion behavior |
|---|---|---|---|
| **Evidence strip** | Identifies source type, year, and why the artefact matters. | Fades upward 10px once when unlocked. | Immediately visible. |
| **Image comparison** | Helps learners observe material differences before reading an explanation. | Crossfades between two static states. | One state appears; controls switch instantly. |
| **Process map** | Shows a sequence, loop, or relationship. | Each node reveals in a 45ms stagger and the active connector brightens. | All nodes appear immediately; active state is indicated by colour and label. |
| **Answer feedback** | Makes a correct/incorrect choice and its rationale clear. | Short 180ms opacity/translate feedback plus a one-time check stroke. | Text status and static icon appear instantly. |
| **Unlock transition** | Connects completing a block to the next available block. | Current block settles to completed state and next block dissolves in over 240ms. | State switches immediately with an explicit text update. |
| **Mini-game board** | Signals a small, low-stakes practice space. | Selected cards lift 4px; placed cards settle with 160ms transform. | Selected/placed states change with colour, border, and text only. |

The implementation must share course-level variables rather than scatter unique timing: `--learn-motion-fast: 150ms`, `--learn-motion-standard: 240ms`, `--learn-motion-slow: 420ms`, `--learn-ease: cubic-bezier(.16, 1, .3, 1)`, and `--learn-distance: 10px`. All motion is limited to `transform` and `opacity` where practical. No game uses a required timer, hover-only control, drag-only action, endless animation, or score-only feedback.

## From No AI to Know AI

## Source and accessibility decisions

Each direct-use external image will be added to the asset register before it is rendered in a course. File-page credits remain available in the final course source panels. Complex source artefacts receive a nearby text explanation, and all mini games retain a native-button, one-tap alternative to drag or hover. Source-dependent factual statements will be linked in their corresponding evidence blocks.
