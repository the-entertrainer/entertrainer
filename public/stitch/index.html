    A few useful details

    Use the move buttons, a position number, or drag the grip to reorder files. The stack runs from top to bottom.

    Choose pages with 1-3, 5. Reverse a range with 5-1. Repeated page numbers repeat those pages. Leave the field blank for all pages.

    Rotation applies to selected pages in that file. Password-protected PDFs need an unlocked copy.

    Page content is copied. Document bookmarks, attachments, signatures and interactive form behaviour are not preserved.

    Available memory limits file size. Close other tabs or split very large jobs. Files are held only for this session; closing or reloading clears the stack.

    Once “Offline ready” appears, reopen this address without a connection. Your browser can remove offline storage; installation does not prevent that.
